# /registrar-adr — Registrar decisão de arquitetura

1. Ler `docs/templates/ADR-TEMPLATE.md` e o índice em `docs/adr/`.
2. Redigir o ADR com número sequencial: contexto (o problema real), alternativas consideradas
   (mínimo 2, com trade-offs honestos), decisão, consequências (incluindo as negativas aceitas).
3. Atualizar `docs/decisoes.md` linkando a decisão D# ao ADR.
4. ADRs são imutáveis após aceitos: mudanças geram novo ADR que substitui o anterior.
